# 📅 تقویم درسی و برنامه مطالعاتی

اپلیکیشن تحت‌وب (PWA) فارسی و کاملاً آفلاین برای برنامه‌ریزی مطالعه: برنامه هفتگی، اهداف، یادآور شبانه، نمودار پیشرفت، پومودورو ۲۵/۵، ماتریس آیزنهاور و سیستم پاداش و جریمه.

## نصب روی موبایل (PWA)

1) این صفحه را روی یک هاست **HTTPS** باز کنید (مثلاً GitHub Pages، Netlify یا Cloudflare Pages؛ رایگان است).
2) لینک را در کروم اندروید باز کنید ← منو ← «Install app / افزودن به صفحه اصلی».
   در آیفون: Safari ← Share ← Add to Home Screen.
3) بعد از اولین باز کردن، آفلاین هم کار می‌کند. داده‌ها فقط روی همان گوشی ذخیره می‌شوند (از «تنظیمات ← پشتیبان» استفاده کنید).

> توجه: باز کردن مستقیم index.html از حافظه گوشی قابل نصب نیست؛ نصب به HTTPS نیاز دارد.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `index.html` | کل اپلیکیشن (HTML + CSS + JS در یک فایل) |
| `manifest.json` | مشخصات PWA |
| `sw.js` | سرویس‌ورکر برای کار آفلاین |
| `planner.md` | نسخه چاپی برنامه برای Notion / Word / چاپ |
| `icons/` | آیکون‌های ۱۹۲ و ۵۱۲ پیکسلی |
