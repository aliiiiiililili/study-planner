نصب روی موبایل (PWA)
1) پوشه را روی یک هاست HTTPS بگذار (مثلاً GitHub Pages، Netlify یا Cloudflare Pages؛ رایگان است).
2) لینک را در کروم اندروید باز کن ← منو ← «Install app / افزودن به صفحه اصلی».
   در آیفون: Safari ← Share ← Add to Home Screen.
3) بعد از اولین باز کردن، آفلاین هم کار می‌کند. داده‌ها فقط روی همان گوشی ذخیره می‌شوند (از «تنظیمات ← پشتیبان» استفاده کن).

توجه: باز کردن مستقیم index.html از حافظه گوشی قابل نصب نیست؛ نصب به HTTPS نیاز دارد.
